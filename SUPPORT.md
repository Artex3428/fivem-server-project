# Support

This repository is an open-source project and does not provide guaranteed
support or response times.

## Bugs

If you believe you found a reproducible bug in this project, open a GitHub
issue and include:

- The affected resource
- What you expected to happen
- What actually happened
- Relevant console errors
- Steps to reproduce the problem
- Any modifications made after installation

## Installation Problems

Before reporting an installation problem:

- Follow the current README instructions
- Confirm that all Git submodules were downloaded
- Confirm that MariaDB/MySQL is available
- Confirm that the database installation completed successfully
- Confirm that you are using the intended FiveM Enhanced server artifacts
- Check the server and txAdmin console for errors

For txAdmin installations, also include the failed recipe task and its complete
error output.

## Feature Requests

Feature suggestions may be submitted through GitHub issues when appropriate.

Please explain the intended use case rather than only requesting a specific
implementation.

## Security Issues

Do not use public support channels for exploitable security vulnerabilities.

Follow the instructions in [SECURITY.md](SECURITY.md).

## Third-Party Resources

If an issue originates entirely from an upstream dependency and is unrelated
to this project's modifications or configuration, the original resource
maintainer may be the appropriate place to report it.
